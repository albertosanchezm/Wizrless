**Game**: Wizrless — metroidvania action-platformer. Wizard/son-of-a-demon hunted by his own order. PC/Steam, solo dev.

**Three Pillars**:
1. Spell Alchemy — depth from emergent spell interactions, not more content
2. Earned Truth — story delivered through boss fights/dialogue, not passive lore
3. Controlled Ascension — start constrained, earn every unlock

**Anti-pillar relevant to Movement**: "NOT punishing platforming — movement is traversal; combat is the test."

**Design pipeline status (2026-04-27)**:
- Input System: Designed
- Audio System: Designed
- Save/Load System: Designed
- Camera System: In Review
- Health System: In Review
- Movement System: In Design (Sections A/B written; Section C = Detailed Design is the current work item)

**Why:** Movement System Detailed Design (Section C) is being authored now — the user provided all locked decisions and needs the full design spec in one pass.

**How to apply:** When working on Movement System, treat the locked decisions as immutable. Don't propose alternatives to them. Build the state machine and rules on top of them.
